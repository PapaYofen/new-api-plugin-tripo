# Tripo task plugin

A New API task plugin for Tripo 3D generation, mesh processing, and file upload.

The publishable files are in `plugins/tasks/tripo/1.0.0/`, next to `plugin.js`:

- `plugin.js`
- `README.md` and `README.zh-CN.md`
- `CHANGELOG.md` and `CHANGELOG.zh-CN.md`

On the community site, submit `PapaYofen/new-api-plugin-tripo/plugins/tasks/tripo/1.0.0` at tag `plugins/tasks/tripo/1.0.0/v1.0.0`.
